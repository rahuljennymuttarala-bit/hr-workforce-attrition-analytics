# HR Workforce Attrition Analytics

An HR workforce analytics and attrition analysis project built using **Microsoft Excel, Power BI, and DAX**.

The project focuses on analyzing employee workforce trends, attrition, attendance, training, performance, and compensation to provide actionable HR insights and support data-driven workforce decisions.

---

## 📊 Project Overview

This project transforms HR workforce data into an interactive Power BI analytics solution.

The dashboard helps HR teams and management understand:

- Workforce size and employee distribution
- Employee attrition and retention patterns
- Department-wise workforce trends
- Attendance and workforce behavior
- Training and development metrics
- Employee performance
- Compensation and salary-related insights
- Key HR performance indicators

---

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data preparation and initial analysis
- **Power BI** – Data modeling, visualization, and dashboard development
- **DAX** – Calculated measures and analytical KPIs
- **Power Query** – Data transformation and cleaning
- **GitHub** – Project documentation and portfolio management
